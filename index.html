        Edit access

        Anyone with the link can look at this album. To add photos, move them, rename folders or comment, this browser needs a GitHub key. The key stays in this browser only.

        Smart suggestions

        Suggests tags, and folders for your Unsorted photos, by looking at the pictures. It runs privately on this device. The first time, it downloads a 23 MB AI model.

        How to get a key (about a minute)
        1. Open GitHub → new fine-grained token (sign in as the album owner).
        2. Name it something like Artist Album and pick an expiration (for example 1 year).
        3. Under Repository access choose Only select repositories → .
        4. Under Permissions → Repository permissions, set Contents to Read and write.
        5. Click Generate token, copy it, and paste it above.
        Let someone else edit

        Send them an invite link. It contains your key, so anyone who has the link can edit or delete photos. Only share it with people you trust. You can cancel all invites at any time by deleting the token on GitHub.

        Safer option: add them as a collaborator on the GitHub repo, so they can create their own key.
